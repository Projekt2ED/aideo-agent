# Cultural Sensitivity Skill（文化敏感性技能）

## 概述

本技能为 Compliance Officer 提供文化敏感性审核的知识库和检查清单，覆盖宗教禁忌、地域偏见、文化符号使用和语言敏感性四大维度。

---

## 一、宗教禁忌清单

### 1.1 佛教禁忌

| 类别 | 禁忌内容 | 严重程度 | 示例 |
|------|---------|---------|------|
| 佛像使用 | 佛像不得用于商业装饰、踩踏、不当摆放 | P0 | 佛像作为花瓶、佛头雕塑踩在脚下 |
| 僧侣形象 | 僧侣不得参与世俗活动、不得被嘲笑 | P1 | 僧侣饮酒、僧侣参与商业活动 |
| 宗教手势 | 不得模仿佛手势用于娱乐 | P1 | 模仿佛像手势自拍 |
| 动物象征 | 不得伤害或贬低佛教圣物 | P1 | 踩踏莲花、伤害白象 |
| 宗教场所 | 寺庙内不得喧哗、不得穿鞋进入 | P2 | 寺庙内大声喧哗 |

**东南亚佛教特别注意：**
- 泰国：冒犯佛教最高可判 7 年监禁
- 缅甸：佛教为国教，需特别尊重
- 斯里兰卡：佛像不得纹身

### 1.2 伊斯兰教禁忌

| 类别 | 禁忌内容 | 严重程度 | 示例 |
|------|---------|---------|------|
| 先知形象 | 禁止描绘先知穆罕默德形象 | P0 | 任何先知形象的描绘 |
| 猪肉 | 禁止展示猪肉及其制品 | P0 | 展示猪肉菜肴、猪形象 |
| 酒精 | 禁止展示饮酒或酒精广告 | P0 | 角色饮酒、酒精产品展示 |
| 裸露 | 严格禁止裸露和性暗示 | P0 | 裸露、紧身衣、性暗示 |
| 左手 | 左手为不洁，不得用于递物或进食 | P1 | 用左手递食物 |
| 脚底 | 不得用脚指向他人或神圣物品 | P1 | 用脚指向清真寺 |
| 斋月 | 斋月期间不得在公开场合进食 | P1 | 白天公开进食 |

**伊斯兰教特别注意：**
- 穆斯林社区对内容审核非常严格
- 斋月期间商业活动需配合
- 清真认证对产品推广至关重要

### 1.3 印度教禁忌

| 类别 | 禁忌内容 | 严重程度 | 示例 |
|------|---------|---------|------|
| 牛 | 牛为神圣动物，不得伤害或食用 | P0 | 展示牛肉菜肴、伤害牛 |
| 宗教符号 | 不得随意使用 Om、Swastika 等符号 | P1 | 将 Om 符号用于商业 Logo |
| 宗教人物 | 不得贬低或戏谑印度教神祇 | P0 | 印度教神祇的搞笑模仿 |
| 左手 | 左手为不洁，不得用于进食 | P2 | 用左手吃东西 |
| 鞋子 | 进入寺庙必须脱鞋 | P2 | 穿鞋进入寺庙 |

**印度教特别注意：**
- 牛在印度地位极高，需特别尊重
- Swastika 为印度教吉祥符号，非纳粹标志
- 印度教神祇形象多样，需避免不当使用

### 1.4 基督教禁忌

| 类别 | 禁忌内容 | 严重程度 | 示例 |
|------|---------|---------|------|
| 十字架 | 不得用于亵渎或商业装饰 | P1 | 十字架作为时尚配饰、酒吧装饰 |
| 圣经 | 不得断章取义或曲解经文 | P1 | 故意曲解圣经内容 |
| 耶稣形象 | 不得戏谑或贬低耶稣形象 | P0 | 耶稣的搞笑模仿 |
| 教堂 | 教堂内不得喧哗或不当行为 | P2 | 教堂内大声喧哗 |
| 圣诞节 | 圣诞节内容需尊重宗教含义 | P2 | 将圣诞节完全商业化 |

**基督教特别注意：**
- 不同教派（天主教、新教、东正教）有差异
- 圣诞节、复活节为重要节日
- 避免将宗教符号过度商业化

### 1.5 犹太教禁忌

| 类别 | 禁忌内容 | 严重程度 | 示例 |
|------|---------|---------|------|
| 神名 | 不得随意书写或说出神的名 | P1 | 随意使用"YHWH" |
| 安息日 | 安息日不得工作 | P2 | 展示安息日工作 |
| 食物 | 需符合 Kosher 规范 | P1 | 展示非 Kosher 食物 |
| 大屠杀 | 不得戏谑或否认大屠杀 | P0 | 大屠杀的搞笑模仿 |
| 六芒星 | 不得用于不当场合 | P1 | 六芒星用于酒吧装饰 |

**犹太教特别注意：**
- 大屠杀历史极为敏感
- Kosher 食品规范严格
- 不同派别（正统派、保守派、改革派）有差异

## 三、文化符号使用规范

### 3.1 国旗使用

| 国家/地区 | 使用限制 | 风险等级 | 注意事项 |
|----------|---------|---------|---------|
| 美国 | 不得用于商业装饰、不得踩踏 | P1 | 星条旗不得用于服装、餐具 |
| 中国 | 不得用于商业广告、不得污损 | P0 | 五星红旗使用需特别谨慎 |
| 日本 | 不得用于商业装饰 | P2 | 日之丸旗使用需注意场合 |
| 德国 | 不得用于非官方场合 | P1 | 德国国旗与纳粹标志需区分 |
| 以色列 | 不得用于可能引起争议的场合 | P1 | 六芒星与国旗需区分 |
| 泰国 | 冒犯国旗等同冒犯王室 | P0 | 泰国国旗使用需特别谨慎 |

**通用规则：**
- 国旗不得用于商业广告或产品包装
- 国旗不得踩踏、污损或不当使用
- 国旗不得用于背景装饰
- 国旗图案不得用于服装、餐具等日常用品

### 3.2 宗教符号使用

| 符号 | 来源 | 使用限制 | 风险等级 |
|------|------|---------|---------|
| 十字架 | 基督教 | 不得用于商业装饰、酒吧装饰 | P1 |
| 六芒星 | 犹太教 | 不得用于不当场合、需与纳粹标志区分 | P1 |
| Om 符号 | 印度教 | 不得用于商业 Logo、时尚配饰 | P1 |
| 新月 | 伊斯兰教 | 不得用于非宗教场合 | P1 |
| 法轮 | 佛教 | 不得用于商业装饰、需庄重使用 | P1 |
| 万字符 | 印度教/佛教 | 需与纳粹标志明确区分 | P0 |

**通用规则：**
- 宗教符号不得用于商业广告
- 宗教符号不得用于娱乐或搞笑场景
- 宗教符号不得用于酒吧、夜店等场所装饰
- 宗教符号的使用需尊重其宗教含义

### 3.3 历史人物使用

| 人物类型 | 使用限制 | 风险等级 | 注意事项 |
|---------|---------|---------|---------|
| 政治领袖 | 不得戏谑或贬低 | P0 | 各国在世/已故领导人 |
| 宗教人物 | 不得戏谑或贬低 | P0 | 耶稣、穆罕默德、佛陀等 |
| 历史名人 | 需尊重其历史地位 | P1 | 爱因斯坦、甘地等 |
| 争议人物 | 需特别谨慎 | P0 | 希特勒、斯大林等 |

**通用规则：**
- 不得戏谑或贬低任何历史人物
- 不得将历史人物用于商业广告
- 争议历史人物（如希特勒）不得以任何方式使用
- 需注意不同国家对同一历史人物的不同看法

- [ ] 是否有表面无害但有性暗示的双关语？
- [ ] 是否有包含种族歧视的俚语？
- [ ] 是否有包含宗教冒犯的俚语？
- [ ] 是否有包含地域歧视的俚语？
- [ ] 是否有在其他文化中有负面含义的词汇？

### 4.3 翻译敏感性

| 问题类型 | 风险 | 说明 | 检查方法 |
|---------|------|------|---------|
| 直译导致的冒犯 | P1 | 直译可能导致文化冒犯 | 请母语者审核 |

**检查清单：**

- [ ] 语气是否与原文相符？
- [ ] 敬语使用是否恰当？
- [ ] 是否有在目标语言中有负面含义的词汇？
