# Script Analysis Review Skill（剧本分析审核技能）

## 概述

本技能为 Compliance Officer 提供剧本审核的知识库和检查清单，覆盖叙事结构、角色一致性、对白质量三大维度。用于 Gate 1 阶段对 `outputs/01-director-analysis.md` 进行合规与质量审核。

---

## 一、叙事结构审核清单

### 1.1 完整性检查

| 检查项 | 标准 | 风险等级 | 检查方法 |
|--------|------|---------|---------|
| 开头引入 | 是否有清晰的背景设定和人物引入 | P2 | 检查前 10% 内容 |
| 冲突建立 | 是否有明确的核心冲突 | P1 | 检查前 25% 内容 |
| 情节发展 | 是否有递进的情节发展 | P1 | 检查中段内容 |
| 高潮设置 | 是否有情感或戏剧高潮 | P1 | 检查后 25% 内容 |
| 结局收束 | 是否有完整的结局和情感收束 | P1 | 检查最后 10% 内容 |

**完整性检查清单：**
- [ ] 开头是否清晰介绍了背景和人物？
- [ ] 核心冲突是否在前 25% 建立？
- [ ] 情节是否有递进发展？
- [ ] 是否有情感或戏剧高潮？
- [ ] 结局是否完整收束？
- [ ] 是否有未解决的伏笔或悬念？

### 1.2 连贯性检查

| 检查项 | 标准 | 风险等级 | 检查方法 |
|--------|------|---------|---------|
| 因果关系 | 情节发展是否有因果逻辑 | P1 | 检查情节转折点 |
| 时间线 | 时间线是否清晰一致 | P1 | 检查时间标记 |
| 空间关系 | 场景转换是否合理 | P2 | 检查场景描述 |
| 信息传递 | 信息是否及时传递给观众 | P2 | 检查关键信息点 |

**连贯性检查清单：**
- [ ] 情节发展是否有因果逻辑？
- [ ] 时间线是否清晰一致？
- [ ] 场景转换是否合理？
- [ ] 关键信息是否及时传递？
- [ ] 是否有逻辑漏洞或矛盾？
- [ ] 是否有突兀的情节转折？

### 1.3 节奏感检查

| 检查项 | 标准 | 风险等级 | 检查方法 |
|--------|------|---------|---------|

### 1.4 悬念设置检查
