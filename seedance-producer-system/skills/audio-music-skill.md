# Audio & Music Skill - 音频音乐技能

**版本：1.0**
**角色：Audio Designer（音频设计师）**
**层级：执行层**

---

## 1. 技能定位

为 Seedance 视频提供音效和配乐指导，确保音频与视觉内容完美配合。

本技能负责定义音效设计、配乐选择、节奏匹配等音频要素，为 Storyboard Artist 编写分镜时提供音频维度的专业支持。

---

## 2. 触发条件

- Phase 3 Storyboard Artist 编写分镜时
- 需要为场景添加音效或配乐指导时
- 需要使用 @audio 引用素材时

### 4.2 节奏匹配

#### 快节奏 (120+ BPM)
```
适用场景：动作、追逐、派对、运动
特征：强烈的节拍感、快速的音符变化
Seedance 提示词：
- Fast-paced, high energy, driving beat
- Energetic rhythm, rapid tempo, pulsating
- 140 BPM, intense, action-packed
```

#### 中节奏 (80-120 BPM)
```
适用场景：叙事、对话、日常、展示
特征：平衡的节奏感、稳定的推进
Seedance 提示词：
- Medium tempo, steady rhythm, balanced pace
- Walking pace, moderate energy, flowing
- 100 BPM, comfortable tempo, natural flow
```

#### 慢节奏 (60-80 BPM)
```
适用场景：情感、回忆、冥想、浪漫
特征：舒缓的节拍、留白和呼吸空间
Seedance 提示词：
- Slow tempo, gentle pace, relaxed rhythm
- Ballad tempo, breathing space, emotional
- 70 BPM, contemplative, unhurried
```

### 4.3 情绪曲线

#### 上升型 (Rising)
```
结构：从平静逐渐走向高潮
适用：激励、成长、发现、觉醒
提示词示例：Building intensity, gradually rising, crescendo
```

#### 下降型 (Falling)
```
结构：从高潮逐渐回归平静
适用：释然、结束、回忆、沉思
提示词示例：Gradually fading, descending melody, calming down
```

#### 波浪型 (Wave)
```
结构：起伏交替，有节奏的情绪波动
适用：爱情、冲突、对话、蒙太奇
提示词示例：Undulating rhythm, emotional waves, dynamic contrast
```

#### 突变型 (Break)
```
结构：突然的情绪转变
适用：惊悚、转折、意外、反差
提示词示例：Sudden shift, dramatic pause, unexpected change
```

#### 平稳型 (Steady)
```
结构：保持一致的情绪基调
适用：展示、教程、纪录片、氛围
提示词示例：Consistent mood, steady atmosphere, maintained tone
```

## 5. Seedance 音频提示词格式

### 5.1 @audio 引用规范

#### 基本格式
```
@audio1 as [用途描述]
```

#### 用途类型

| 用途 | 格式 | 示例 |
|------|------|------|
| 背景音乐 | @audioN as background music | @audio1 as background music |
| 动作参考 | @audioN as action rhythm reference | @audio2 as dance rhythm reference |
| 环境音 | @audioN as ambient sound | @audio3 as rain ambient |
| 音效参考 | @audioN as sound effect reference | @audio1 as impact sound reference |
| 情绪参考 | @audioN as mood reference | @audio2 as tension mood reference |

### 5.2 音频提示词写法

#### 在提示词中描述音频期望

```
配合舒缓钢琴BGM，节奏缓慢
With slow, gentle piano background music, relaxing tempo

伴随紧张的电子音乐，节奏逐渐加快
Accompanied by tense electronic music, gradually increasing tempo

环境音：雨声 + 远处雷声 + 偶尔车过水洼声
Ambient sounds: rain, distant thunder, occasional car splashing through puddles
```

#### 音频与画面同步

```
[0s-3s] 轻柔环境音，建立氛围
[3s-6s] BGM开始，与画面节奏匹配
[6s-10s] 音乐情绪跟随画面转折
[10s-15s] 音乐渐弱或突停，配合画面结束
```

### 5.3 音频限制提醒

| 限制项 | 数值 |
|--------|------|
| 音频文件数量 | 最多 3 个 |
| 单个文件大小 | <15MB |
| 单个文件时长 | 最长 15 秒 |
| 总引用数量 | 最多 12 个（含图片和视频） |

## 6. 输出格式

### 6.1 输出文件

本技能的输出嵌入到以下文件中：
- `outputs/03-seedance-prompts.md` - 音效配乐指导嵌入分镜

### 6.2 输出内容结构

每个分镜应包含以下音频信息：

```markdown
#### 分镜 #N 音频指导

**音效 (SFX)**：
- [音效1]: [描述]
- [音效2]: [描述]

**配乐 (BGM)**：
- 风格: [音乐风格]
- 节奏: [BPM]
- 情绪: [情绪描述]
- 乐器: [主要乐器]

**环境音 (Ambient)**：
- [环境音1]: [描述]
- [环境音2]: [描述]

**@audio 引用**：
- @audio1 as [用途]

**音频提示词**：
[英文音频描述，可直接用于 Seedance]
```

## 7. 音频设计工作流程

```
接收分镜内容
    ↓
分析每个分镜的视觉内容
    ↓
确定情绪基调和节奏需求
    ↓
选择合适的音效类型
    ↓
选择合适的配乐风格
    ↓
设计环境音层
    ↓
编写音频提示词
    ↓
检查音频与画面同步
    ↓
输出到 03-seedance-prompts.md
```

## 8. 常见场景音频设计模板

### 8.1 动作追逐场景

```
音效：急促脚步、喘息、碰撞、车辆引擎
配乐：快节奏电子/摇滚，140+ BPM，紧张激烈
环境音：城市噪音、风声、警笛（可选）
提示词：High-energy electronic music, driving beats, 
tense atmosphere, rapid tempo, action-packed rhythm
```

### 8.2 浪漫约会场景

```
音效：轻柔交谈、杯碟声、远处音乐
配乐：爵士/钢琴曲，70-90 BPM，温柔浪漫
环境音：咖啡馆氛围、轻柔背景人声
提示词：Romantic jazz, smooth saxophone, gentle piano, 
warm intimate atmosphere, soft lighting mood
```

### 8.3 悬疑惊悚场景

```
音效：心跳、呼吸、门吱呀、远处低语
配乐：暗黑氛围，低频嗡鸣，不协和弦
环境音：寂静中的细微声响、风声
提示词：Suspenseful atmosphere, low frequency drone, 
dissonant chords, eerie silence, tension building
```

### 8.4 自然风光场景

```
音效：鸟鸣、风声、流水、树叶沙沙
配乐：新世纪/环境音乐，60-80 BPM，平静祥和
环境音：自然环境音，层次丰富
提示词：Peaceful nature ambience, gentle wind, birdsong, 
flowing water, new age meditation music, serene
```

### 8.5 科技未来场景

```
音效：电子蜂鸣、全息投影、机械运动
配乐：合成器/电子乐，100-120 BPM，未来感
环境音：低频嗡鸣、电子环境音
提示词：Futuristic electronic, synthwave, cyberpunk beats, 
holographic sounds, technological atmosphere
```
