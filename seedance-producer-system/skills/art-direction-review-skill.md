# Art Direction Review Skill（美术方向审核技能）

## 概述

本技能为 Compliance Officer 提供美术方向审核的知识库和检查清单，覆盖视觉一致性、版权排查两大维度。用于 Gate 2 阶段对 `outputs/02-character-prompts.md` 和 `outputs/02-scene-prompts.md` 进行合规与质量审核。

---

## 一、视觉一致性审核清单

### 1.1 色调统一检查

| 检查项 | 标准 | 风险等级 | 检查方法 |
|--------|------|---------|---------|
| 主色调 | 全片是否有统一的主色调 | P2 | 对比各场景色彩 |
| 色彩饱和度 | 色彩饱和度是否一致 | P2 | 对比各场景饱和度 |
| 色温 | 色温是否一致或有逻辑变化 | P2 | 对比各场景色温 |
| 色彩对比 | 色彩对比度是否一致 | P2 | 对比各场景对比度 |

**色调统一检查清单：**
- [ ] 全片是否有统一的主色调？
- [ ] 色彩饱和度是否一致？
- [ ] 色温是否一致或有逻辑变化？
- [ ] 色彩对比度是否一致？
- [ ] 是否有突兀的色彩变化？
- [ ] 色彩是否服务于叙事？

## 二、版权排查清单

### 2.1 知名 IP 元素检查

| 检查项 | 风险等级 | 检查方法 | 处理建议 |
|--------|---------|---------|---------|
| 角色形象 | P0 | 对比知名 IP 角色 | 移除或重新设计 |
| 场景设计 | P1 | 对比知名 IP 场景 | 修改或重新设计 |
| 道具设计 | P1 | 对比知名 IP 道具 | 修改或重新设计 |
| 标志性元素 | P0 | 对比知名 IP 标志 | 移除或重新设计 |

**知名 IP 元素检查清单：**
- [ ] 是否有类似迪士尼角色的形象？
- [ ] 是否有类似漫威角色的形象？
- [ ] 是否有类似 DC 角色的形象？
- [ ] 是否有类似日本动漫角色的形象？
- [ ] 是否有类似游戏 IP 的元素？
- [ ] 是否有类似电影 IP 的元素？

**常见需避免的 IP：**
- 迪士尼/皮克斯角色
- 漫威/DC 超级英雄
- 宝可梦/任天堂角色
- 日本动漫角色（海贼王、火影等）
- 游戏角色（马里奥、塞尔达等）

### 2.2 商标检查

| 检查项 | 风险等级 | 检查方法 | 处理建议 |
|--------|---------|---------|---------|
| 品牌 Logo | P0 | 对比知名品牌 Logo | 移除或模糊 |
| 品牌名称 | P0 | 检查文字中是否出现品牌名 | 移除或替换 |
| 品牌产品 | P1 | 检查是否展示品牌产品 | 模糊或替换 |
| 品牌色彩 | P2 | 检查是否使用品牌标志性色彩 | 修改色彩 |

**商标检查清单：**
- [ ] 是否有知名品牌的 Logo？
- [ ] 是否有知名品牌名称？
- [ ] 是否有知名品牌产品？
- [ ] 是否有品牌标志性色彩？
- [ ] 是否有品牌标志性图案？

**常见需避免的商标：**
- 科技品牌（Apple, Google, Microsoft 等）
- 时尚品牌（Louis Vuitton, Gucci, Nike 等）
- 汽车品牌（BMW, Mercedes, Tesla 等）
- 食品品牌（Coca-Cola, McDonald's 等）
- 社交媒体（Instagram, TikTok, YouTube 等）

### 2.3 品牌标识检查

| 检查项 | 风险等级 | 检查方法 | 处理建议 |
|--------|---------|---------|---------|
| 真实品牌 | P0 | 检查是否出现真实品牌 | 移除或替换 |
| 虚构品牌 | P2 | 检查虚构品牌是否与真实品牌相似 | 修改设计 |
| 品牌暗示 | P2 | 检查是否有品牌暗示 | 修改设计 |

**品牌标识检查清单：**
- [ ] 是否有真实品牌标识？
- [ ] 虚构品牌是否与真实品牌相似？
- [ ] 是否有品牌暗示？
- [ ] 是否有品牌色彩暗示？
- [ ] 是否有品牌形状暗示？

### 2.4 地理标志检查

| 检查项 | 风险等级 | 检查方法 | 处理建议 |
|--------|---------|---------|---------|
| 地标建筑 | P1 | 检查是否出现真实地标 | 确认授权或修改 |
| 地名 | P2 | 检查是否使用真实地名 | 确认使用权限 |
| 地图 | P1 | 检查地图是否准确 | 确认地图准确性 |

**地理标志检查清单：**
- [ ] 是否有真实地标建筑？
- [ ] 是否使用真实地名？
- [ ] 地图是否准确？
- [ ] 是否有领土争议的地图？

### 2.5 人物肖像检查

| 检查项 | 风险等级 | 检查方法 | 处理建议 |
|--------|---------|---------|---------|
| 真实人物 | P0 | 检查是否类似真实人物 | 修改设计 |
| 名人肖像 | P0 | 检查是否类似名人 | 修改设计 |
