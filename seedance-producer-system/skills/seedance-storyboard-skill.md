**层级：执行层**

## 1. 技能定位

编写 Seedance 2.0 动态视频提示词的核心技能。

本技能的目标不是写"还行"的提示词，而是写**导演级提示词**——精确到胶片型号、掌镜人、色号、运镜风格、音轨策略，让 Seedance 生成的视频具有电影级质感。

### 与 v1.0 的核心区别

| 维度 | v1.0（旧） | v2.0（新） |
|------|-----------|-----------|
| 风格描述 | "cinematic, photorealistic" | `[STYLE LOCK]` 指定胶片型号+掌镜人+LUT |
| 色彩控制 | "warm golden lighting" | `@[色卡]` 锚定 + 精确色号 #F5C078 |
| 运镜写法 | "camera slowly pushes in" | 导演风格命名："Spielberg式over-shoulder reveal" |
| 音轨位置 | 文末附带 | 开头先行声明，文末闭环 |
| 锚点概念 | 无 | 贯穿全程的核心实体明确声明 |
| 时间线 | `[0s]` `[3s]` | "画面第一秒" "画面第二秒"，描述更细腻 |
| 细节层级 | "photorealistic, 4K" | "发丝过曝飞扬、鼻息在刃面凝起薄雾" |

## 2. 段落类型体系

每个分镜/镜头段落在开头必须声明其类型，不同类型的提示词结构不同。

### 2.1 段落类型清单

| 类型 | 说明 | 适用场景 | 典型时长 |
|------|------|---------|---------|
| **首尾帧生成** | 给定起始帧和结束帧，中间自动过渡 | 场景转换、时间流逝、情绪变化 | 5-15s |
| **运镜段落** | 以镜头运动为核心驱动 | 揭示运镜、环绕展示、跟踪拍摄 | 5-15s |
| **空镜段落** | 无主体人物，以环境/氛围为主 | 环境建立、情绪铺垫、时间过渡 | 5-10s |
| **动作段落** | 以人物动作为核心 | 打斗、舞蹈、追逐、仪式 | 5-15s |
| **对话段落** | 以人物对话/对视为核心 | 文戏、谈判、情感交流 | 8-15s |
| **特写段落** | 以面部/物体细节为核心 | 表情变化、道具揭示、情绪锚点 | 3-8s |

### 2.2 不同类型的结构差异

**首尾帧生成**：必须明确描述起幅画面和收幅画面，中间描述连续过渡

**运镜段落**：必须用导演风格命名运镜，详细描述镜头运动轨迹

**空镜段落**：重点在环境细节、光影变化、声场设计

**动作段落**：重点在动作的物理细节（力的方向、速度、身体力学）

**对话段落**：重点在面部微表情、眼神交流、空间关系

**特写段落**：重点在材质细节（皮肤纹理、布料褶皱、光反射）

## 3. [STYLE LOCK] 风格锁定

### 3.1 什么是 STYLE LOCK

每段提示词必须以 `[STYLE LOCK]` 开头，用最精确的语言锁定本段的视觉风格。

**STYLE LOCK 不是写"cinematic"或"photorealistic"。**

STYLE LOCK 是指定：
- 用什么胶片/数字质感拍
- 谁掌镜（参考哪位摄影师）
- 参考哪部电影的哪个场景的美学
- 用什么 LUT/调色风格
- 用什么镜头（anamorphic/spherical/定焦/变焦）
- 画幅比例是多少
- 颗粒/质感描述

### 3.2 STYLE LOCK 格式

```
[STYLE LOCK]
[胶片型号/数字质感],[掌镜人参考],[美学参考电影+具体场景],[LUT/调色风格],[镜头类型],[颗粒/质感描述],[画幅比例]。
```

## 4. @[引用系统] 与素材锚定

### 4.1 引用类型

| 引用类型 | 格式 | 作用 |
|---------|------|------|
| **色卡锚定** | `@[色卡ID]` + 色彩规范 | 锁定整段画面的色彩体系 |
| **环境锚定** | `@[图片ID]` + "作为XXX环境视觉锚定" | 锁定场景环境 |
| **人物锚定** | `@[图片ID]` + "作为XXX视觉锚定" | 锁定人物外观 |
| **服装参考** | `@[图片ID]` + "作为XXX服装风格视觉参考" | 锁定服装语言 |
| **动作参考** | `@[视频ID]` + "作为XXX动作参考" | 锁定动作节奏 |
| **音效参考** | `@[音频ID]` + "作为XXX音效参考" | 锁定音效风格 |

### 4.2 色卡锚定（最核心）

色卡锚定是导演级提示词的关键。通过 `@[色卡ID]` 引用一张预设的色彩表，并在提示词中精确指定本段使用哪些色号。

**格式**：
```
@[色卡ID]  作为整段画面色卡锚定+所有色彩严格按色卡24色执行+不可偏离色板+本段重点调用[主色名称]#[色号]到#[色号]的[描述]+[阴影色名称]#[色号]到#[色号]的阴影层+[环境色名称]#[色号]与#[色号]的环境底色+[强调色名称]#[色号]作为视觉钉子。
```

**示例**：
```
@[8a3a9cc439b45b2a3d05933409154700]  作为整段画面色卡锚定+所有色彩严格按色卡24色执行+不可偏离色板+本段重点调用黄昏直射金光#F5C078到#E89A48的暖金主光+硬阴影暖灰#6B5A47到深棕#4A3E32的阴影层+岩崖砂岩#C9A678与石窟深处#7A5A3E的环境底色+杂货商身上鞣皮褐#8C6F4A与青铜patina#5C7065与未抛光铁灰#4A4640的salvage金属皮革色+朱砂红#A82A2A作为视觉钉子。
```

**色号规范要点**：
- 主色（光源色）：指定色号范围（如 #F5C078 到 #E89A48）
- 阴影层：指定色号范围
- 环境底色：指定色号
- 强调色/视觉钉子：指定色号（用于引导观众注意力的高饱和色点）

## 5. 贯穿锚点

### 5.1 什么是贯穿锚点

贯穿锚点是在整段提示词中**始终存在、始终不变**的核心实体。它们连接首尾帧，保证视觉连续性。

### 5.2 锚点类型

| 锚点类型 | 示例 |
|---------|------|
| **人物锚点** | "小丹眉本人（黑色齐眉短发、红绳流苏发饰、深色立领衣装）" |
| **道具锚点** | "那柄带银白色镂空圆形车轮辐条状护手的长剑" |
| **环境锚点** | "部落崖壁的岩窟群" |
| **光线锚点** | "从幽暗中一束硬窄的炽白逆光" |
| **色彩锚点** | "红穗流苏"（贯穿全程的色彩亮点） |

### 5.3 锚点描述格式

```
全程的锚点：贯穿首尾的是[人物名]本人（[外观关键特征]），以及[道具名]——它在首帧[状态A]，在转换中[状态B]，在收幅[状态C]，是连接首尾的核心实体。[其他贯穿元素]也贯穿始终。
```

### 5.4 锚点的演化

锚点不是静止的。它的**状态**会在首帧→过渡→尾帧之间发生变化，但**存在**始终不变。

```
剑的演化：
- 首帧：被炽白逆光点燃横在脸前
- 转换中：被抬起、转向、亮到身侧
- 尾帧：斜贯画面、剑尖迸出星芒
```

## 6. 运镜体系：导演风格命名

### 6.1 运镜描述的三个层级

| 层级 | 示例 | 适用 |
|------|------|------|
| **基础级** | "camera slowly pushes in" | 通用模板 |
| **专业级** | "slow dolly in, arc movement from over-shoulder to side angle" | 专业提示词 |
| **导演级** | "Spielberg式over-shoulder reveal揭示运镜,镜头平滑绕过杂货商的左肩,从他身后向画面右深处弧形推进arc dolly" | 导演级提示词 |

### 6.2 导演风格运镜命名

| 运镜名称 | 导演参考 | 效果描述 |
|---------|---------|---------|
| **Spielberg式揭示运镜** | Steven Spielberg | 从遮挡物后方绕出，揭示被遮挡的主体 |
| **Scorsese式长镜头** | Martin Scorsese | 一镜到底，跟随人物穿越复杂空间 |
| **Kubrick式对称推进** | Stanley Kubrick | 正面单点透视，缓慢推进，制造压迫感 |
| **Hitchcock式变焦推拉** | Alfred Hitchcock | Dolly+Zoom 反向操作（希区柯克变焦） |
| **Tarantino式仰角特写** | Quentin Tarantino | 低角度仰拍，脚部/手部特写 |
| **Nolan式交叉剪辑** | Christopher Nolan | 多时间线交叉，快速切换 |
| **Wong Kar-Wai式慢镜** | 王家卫 | 升格慢动作、手持晃动、色彩饱和 |
| **Tarkovsky式长镜头** | Andrei Tarkovsky | 极慢推进、环境沉浸、时间凝固 |

### 6.3 复合运镜描述

导演级提示词中，运镜通常是复合的：

```
镜头同步运动：从首帧那个贴近剑身的低角度侧前方机位，
随她的抬身与转身缓缓拉开、并横移环绕到她的侧方，
景别略略拉远、让出身侧斜贯的长剑与身周的空间。
```

拆解：
- 起始机位：贴近剑身的低角度侧前方
- 运动方式：缓缓拉开 + 横移环绕
- 终止机位：她的侧方
- 景别变化：略略拉远
- 目的：让出身侧斜贯的长剑与身周的空间

### 6.4 运镜与人物动作同步

导演级提示词中，镜头运动必须与人物动作**同步描述**：

```
在人物抬身转身的同时，镜头同步以Spielberg式揭示运镜启动：
镜头开始平滑地绕过杂货商的左肩，从他身后向画面右深处弧形推进arc dolly，
镜头一边绕过他的肩膀一边向前推进同时轻微tilt up。
```

## 7. 音轨体系：先行声明 + 音效闭环

### 7.1 音轨先行声明

在画面描述之前，先声明整段的音轨策略：

```
音轨：仅环境音与动作音，不配 BGM。起幅是一种屏息般的寂静——
只余一缕剑鸣余韵与人物克制绵长的呼吸；随抬身转身展开，
叠入衣料摩擦、剑身在空气中划过的破风嗡鸣；收幅过渡到开阔的室外——
旷野的风声呼啸、麦浪被风吹得沙沙翻涌、麦芒摩擦的细响。
```

### 7.2 音轨声明格式

```
音轨：[BGM策略]。[起幅音效描述]；[过程音效描述]；[收幅音效描述]。
```

**BGM 策略选项**：
- "仅环境音与动作音，不配 BGM" — 纪实、沉浸、紧张
- "配以[风格]BGM" — 史诗、情感、商业
- "BGM 从[状态A]过渡到[状态B]" — 有情绪变化的段落

### 7.3 音效分层

| 音效层 | 说明 | 示例 |
|--------|------|------|
| **环境音** | 场景的底噪 | 风声、雨声、城市噪音、空调嗡嗡声 |
| **动作音** | 人物/物体动作产生的声音 | 脚步声、衣料摩擦、剑划破空气、门轴转动 |
| **情绪音** | 强化情绪的声音设计 | 心跳声、呼吸声、剑鸣余韵 |
| **空间音** | 随空间变化的声音 | 室内回声→室外开阔、远近声场变化 |

### 7.4 音效闭环

在画面描述的末尾，必须有完整的音效闭环——从头到尾描述声音的全程变化：

```
全程音效紧贴画面：起幅屏息的寂静与剑鸣余韵、克制的呼吸；
抬身转身时衣料摩擦、剑划破空气的破风嗡鸣；
空间转换为麦田后，旷野风声由弱渐强呼啸、麦浪沙沙翻涌、
麦芒摩擦的细响，紧贴衣摆发丝被风掀动的猎猎声，
收幅归于风与麦浪绵延不断的开阔声场。
```

### 7.5 音效与画面同步原则

- 音效必须**紧贴画面**——画面发生什么，声音就对应什么
- 音效的**强弱变化**与画面的**情绪起伏**同步
- 空间转换时，声场也要转换（室内→室外、近→远）
- 静音也是一种音效设计——"屏息般的寂静"比"没有声音"更有力量

## 8. 画面描述：时间线驱动与细节层级

### 8.1 时间线格式

**首尾帧生成类**：不使用 `[0s]` 标记，而是用叙事性的时间描述：

```
画面第一秒，这块青铜板被两只手缓慢从镜头前向下移开...
画面第二秒，远处的部落人群欢笑歌唱声浪逐渐变响传来...
第三秒，杂货商的身体姿态明显凝固一瞬...
```

**运镜/空镜类**：使用 `[0s]` 标记：

```
[0s] Wide establishing shot: ...
[3s] A black luxury helicopter appears...
[5s] Camera pulls out wider...
[7s] The mansion's front doors open...
```

### 8.2 画面描述的五个维度

| 维度 | 说明 | 示例 |
|------|------|------|
| **空间** | 场景在哪里、空间关系 | "幽暗的室内深蓝暗部"、"白昼的开阔麦田" |
| **人物** | 谁在做什么、身体细节 | "俯首低头、脸贴近横在面前的剑刃" |
| **光线** | 光从哪来、什么颜色、什么质感 | "强窄逆光自侧后方猛烈打来，剑身迎光炸出炽亮冷白高光" |
| **运动** | 人和物怎么动、力的方向 | "以脊柱为轴向右拧转，肩与髋随之转开" |
| **粒子/材质** | 空气中的微粒、表面质感 | "前垂的发缕与几缕过曝飞扬的发丝垂落遮拂" |

### 8.3 细节层级

| 层级 | 描述粒度 | 示例 |
|------|---------|------|
| **宏观** | 整体场景和氛围 | "幽暗的室内" |
| **中观** | 人物动作和光线 | "逆光勾在她脸侧、鼻梁、唇与发丝边缘" |
| **微观** | 材质和粒子 | "鼻息在炽亮刃面上凝起转瞬即散的薄雾" |

导演级提示词必须**三层都有**：宏观定场景、中观定动作、微观定质感。

### 8.4 光线演化描述

光线不是静态的，它随画面变化而演化：

```
光的色温与质地从"幽暗中一束硬窄的炽白逆光"连续过渡为
"白昼旷野柔和开阔的天光"，冷暖关系也从暗冷的蓝黑转为
灰蓝晴空映衬暖金麦田的冷暖对撞。
```

### 8.5 空间消融与重塑

当场景需要转换时，不是"切换"，而是"消融-重塑"：

```
起幅幽暗的室内深蓝暗部，随镜头拉开、随强逆光的光束扩散开来，
一寸寸被涌入的明亮天光稀释、冲淡、漂白——幽暗背景在白光的弥漫中
消融、瓦解，看不出原貌；就在这片漫开的白光里，环境重塑成白昼的
开阔麦田。
```

## 10. 完整示例

### 示例 1：首尾帧生成 + 空间转换

**段落类型**：首尾帧生成
**场景描述**：一个剑客从幽暗室内转换到白昼麦田

**Seedance 提示词**：

```
[STYLE LOCK]
电影级写实 CG，70mm 大画幅胶片质感，颗粒细腻、强烈大气透视。画幅 2.39:1。这是一段首尾帧生成：起幅严格为首帧画面（暗背景强逆光下，小丹眉俯首低头、脸贴近一柄横在面前、被强光打到炽白过曝的剑刃，发丝过曝飞扬），收幅严格为尾帧画面（白昼麦田蓝天下，小丹眉侧身朝右、反握一柄长剑斜贯画面，衣摆被风掀起带动态模糊，剑尖在画面右下迸出星芒状高光，前景金黄麦穗虚化）。中间是一段连续不断、一气呵成的转换。

音轨：仅环境音与动作音，不配 BGM。起幅是一种屏息般的寂静——只余一缕剑鸣余韵与人物克制绵长的呼吸；随抬身转身展开，叠入衣料摩擦、剑身在空气中划过的破风嗡鸣；收幅过渡到开阔的室外——旷野的风声呼啸、麦浪被风吹得沙沙翻涌、麦芒摩擦的细响。

全程的锚点：贯穿首尾的是小丹眉本人（黑色齐眉短发、红绳流苏发饰、深色立领衣装），以及那柄带银白色镂空圆形车轮辐条状护手的长剑——它在首帧被炽白逆光点燃横在脸前，在转换中被抬起、转向、亮到身侧，在尾帧斜贯画面、剑尖迸出星芒，是连接首尾的核心实体。她脸侧垂落的红穗流苏也贯穿始终。

起幅是首帧画面：暗背景、深蓝近黑的环境里，强窄逆光自侧后方猛烈打来，小丹眉俯首低头、脸贴近横在面前的剑刃，剑身迎光炸出接近纯白过曝的炽亮冷白高光、亮得几乎熔进光里，逆光勾在她脸侧、鼻梁、唇与发丝边缘，亮部过曝、暗部沉黑，前垂的发缕与几缕过曝飞扬的发丝垂落遮拂，红穗流苏垂在脸侧。这一刻她近乎静止，只有克制的呼吸让肩背几不可察地起伏、鼻息在炽亮刃面上凝起转瞬即散的薄雾。

连续转换就此展开，一气呵成：先是她俯首的头与上身缓缓抬起——下颌离开剑刃、颈背挺直、脸从贴近剑刃的俯姿抬向前方。随即她开始转身朝向画面右侧——以脊柱为轴向右拧转，肩与髋随之转开，重心移动、身体由暗中朝光里转去；持剑的手腕翻转、把横在脸前的剑亮向身体一侧，剑随转身的动势划过空气、发出破风嗡鸣，最终变为反握姿态。镜头同步运动：从首帧那个贴近剑身的低角度侧前方机位，随她的抬身与转身缓缓拉开、并横移环绕到她的侧方。

在人物抬身转身的同时，整个空间发生消融与重塑：起幅幽暗的室内深蓝暗部，随镜头拉开、随强逆光的光束扩散开来，一寸寸被涌入的明亮天光稀释、冲淡、漂白——幽暗背景在白光的弥漫中消融、瓦解；就在这片漫开的白光里，环境重塑成白昼的开阔麦田。

收幅严格收束到尾帧画面：白昼麦田蓝天下，小丹眉侧身朝向画面右侧、反握长剑——剑身自画面右上向左下方斜贯而出；镜头落到一个贴近地面的低角度仰拍机位，焦平面锁定在画面右下侧剑尖处——剑尖在此迎着白昼强光迸出一处星芒状的炽亮高光。前景大片金黄麦穗贴近镜头大幅虚化成柔软的暖金光斑。画面定格在此，旷野的风与麦浪持续翻涌。

全程音效紧贴画面：起幅屏息的寂静与剑鸣余韵、克制的呼吸；抬身转身时衣料摩擦、剑划破空气的破风嗡鸣；空间转换为麦田后，旷野风声由弱渐强呼啸、麦浪沙沙翻涌、麦芒摩擦的细响，收幅归于风与麦浪绵延不断的开阔声场。
```

**结构分析**：
- STYLE LOCK：电影级 CG + 70mm + 2.39:1
- 段落类型：首尾帧生成
- 音轨先行：仅环境音+动作音，无 BGM
- 锚点：人物（小丹眉）+ 道具（长剑）+ 色彩（红穗流苏）
- 画面描述：宏观（空间）+ 中观（动作）+ 微观（鼻息薄雾）
- 光线演化：硬窄逆光 → 开阔天光
- 空间消融：幽暗室内 → 白昼麦田
- 音效闭环：寂静 → 破风嗡鸣 → 旷野风声

整段镜头中持续伴随夜晚沙漠的低沉风声、远处部落广场聚会即将散场的人群断续不太清晰的交谈欢笑声、零星的鼓点和歌声渐弱、火堆燃烧的低沉噼啪声crackle、岩窟里漏出的微弱说话声、几只远处部落动物的低声鸣叫,所有这些环境声铺满整个声场营造夜晚部落聚会余韵的温暖人间烟火氛围。
```

**结构分析**：
- STYLE LOCK：Kodak 500T + Greig Fraser + Dune 2021 夜景 + skip-bleach
- 段落类型：空镜段落
- 画幅：21:9（比 2.39:1 更宽）
- 运镜：极缓慢 forward push in，有呼吸感
- 光源：暖橙色油灯+火堆 vs 冷色夜空，色温对比
- 音轨先行：7 种声音铺满声场
- @引用：环境锚定 + 色卡（冷蓝+暖橙+深棕）
- 远景延伸：沙漠地平线 + 极光带，增加纵深度
- 音效闭环：末尾统一描述全部环境声
