# 项目管理 Skill

## 技能定位

负责短剧项目的全生命周期管理，从立项到交付的资源分配与进度追踪。

## 触发条件

- 用户输入新的剧本或创作需求
- 用户询问项目进度
- 需要进行资源分配决策

## 输入

- 用户的原始需求描述或剧本文本
- 目标市场信息（如有）
- 预算和时间约束（如有）

## 执行步骤

### Step 1: 需求分析
1. 读取用户输入的剧本或需求描述
2. 识别项目类型：
   - 短剧（1-100 集，每集 1-3 分钟）
   - 短视频（单条 15-60 秒）
   - 品牌宣传片（30-90 秒）
   - 产品展示（15-30 秒）
3. 识别目标市场（北美/欧洲/东南亚/中东/全球）
4. 识别目标平台（TikTok/YouTube/Instagram/其他）

### Step 2: 项目简报生成
1. 使用 `outputs/00-project-brief.md` 模板
2. 填写项目概述（一句话定位）
3. 填写目标市场与受众画像
4. 填写核心创意方向
5. 填写资源需求清单
6. 填写风险评估

### Step 3: 资源分配
1. 确定每个 Phase 的优先级
2. 识别需要的 Skill 模块
3. 确定审核节点和交付标准

### Step 4: 进度追踪
1. 记录每个 Phase 的开始/结束时间
2. 记录 Gate 审核结果
3. 记录修改次数和原因
4. 生成进度报告

## 输出格式

产出文件：`outputs/00-project-brief.md`

## 质量标准

- 项目定位清晰，一句话能说清楚
- 目标市场明确，不超过 2 个主力市场
- 资源需求具体，不模糊
- 风险评估务实，不回避问题
- 时间线合理，不过度承诺
