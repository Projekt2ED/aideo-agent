# Seedance Prompt Review Skill（Seedance 提示词审核技能）

## 概述

本技能为 Compliance Officer 提供 Seedance 提示词审核的知识库和检查清单，覆盖提示词质量、动态质量两大维度。用于 Gate 3 阶段对 `outputs/03-seedance-prompts.md` 进行合规与质量审核。

---

## 一、Seedance 提示词质量审核清单

### 1.1 六步公式完整性检查

Seedance 提示词采用六步公式结构，每个镜头的提示词必须包含以下六个部分：

| 步骤 | 名称 | 说明 | 检查标准 |
|------|------|------|---------|
| Step 1 | 主体描述 | 描述画面中的主要人物或物体 | 是否清晰描述主体特征 |
| Step 2 | 动作描述 | 描述主体的具体动作 | 是否描述具体动作 |
| Step 3 | 场景描述 | 描述画面的环境和背景 | 是否描述场景细节 |
| Step 4 | 运镜描述 | 描述摄像机的运动方式 | 是否指定运镜方式 |
| Step 5 | 风格描述 | 描述画面的视觉风格 | 是否指定视觉风格 |
| Step 6 | 约束描述 | 描述画面的限制条件 | 是否包含约束条件 |

**六步公式完整性检查清单：**
- [ ] 是否包含主体描述？
- [ ] 是否包含动作描述？
- [ ] 是否包含场景描述？
- [ ] 是否包含运镜描述？
- [ ] 是否包含风格描述？
- [ ] 是否包含约束描述？
- [ ] 六步之间的逻辑是否连贯？
- [ ] 六步是否覆盖了画面的所有关键信息？

### 1.2 运镜合理性检查

| 检查项 | 标准 | 风险等级 | 检查方法 |
|--------|------|---------|---------|
| 单一主运镜 | 每个镜头只使用一个主运镜 | P1 | 检查运镜描述 |
| 运镜清晰 | 运镜描述清晰明确 | P1 | 检查运镜描述 |
| 运镜合理 | 运镜方式符合场景需求 | P2 | 检查运镜与场景匹配 |
| 运镜流畅 | 运镜过渡自然流畅 | P2 | 检查运镜过渡 |

**运镜合理性检查清单：**
- [ ] 每个镜头是否只使用一个主运镜？
- [ ] 运镜描述是否清晰明确？
- [ ] 运镜方式是否符合场景需求？
- [ ] 运镜过渡是否自然流畅？
- [ ] 是否有运镜冲突的情况？
- [ ] 是否有运镜过于复杂的情况？

**8种标准运镜术语（与 seedance-storyboard-skill.md 一致）：**
| 运镜类型 | 英文术语 | 适用场景 |
|---------|---------|---------|
| 推进 | Push-in / Dolly In | 特写强调、情感聚焦 |
| 拉远 | Pull-out / Dolly Out | 环境揭示、空间感 |
| 横摇 | Pan | 追踪主体、扫描场景 |
| 跟踪 | Tracking Shot / Follow | 动作场景、行走人物 |
| 环绕 | Orbit / Arc | 产品展示、角色肖像 |
| 航拍 | Aerial / Drone Shot | 风景、城市、宏大场面 |
| 手持 | Handheld | 纪录片风格、真实感 |
| 固定 | Fixed / Locked-off | 聚焦主体动作 |

### 1.3 约束充分性检查

| 检查项 | 标准 | 风险等级 | 检查方法 |
|--------|------|---------|---------|
| 画质约束 | 是否指定画质要求 | P1 | 检查约束描述 |

**约束充分性检查清单：**
- [ ] 是否指定画质要求（如 4K、高清）？
- [ ] 是否指定稳定性要求（如稳定、无抖动）？
- [ ] 是否指定风格要求（如电影感、纪录片风格）？
- [ ] 是否有其他必要约束？
- [ ] 约束是否与目标一致？
- [ ] 约束是否过于严格或过于宽松？

**常见约束类型：**
| 约束类型 | 说明 | 示例 |
|---------|------|------|

| 稳定性约束 | 指定画面稳定性 | "stable shot, no shake" |
| 风格约束 | 指定视觉风格 | "cinematic look, film grain" |
| 光影约束 | 指定光影效果 | "natural lighting, soft shadows" |
| 色彩约束 | 指定色彩效果 | "warm tones, muted colors" |
| 运动约束 | 指定运动效果 | "slow motion, smooth movement" |

**Seedance 能力边界：**
| 能力类型 | 支持程度 | 说明 |
|---------|---------|------|
| 简单动作 | 高 | 走路、跑步、转身等 |
| 中等动作 | 中 | 跳舞、打斗、运动等 |
| 复杂动作 | 低 | 杂技、极限运动等 |
| 物理模拟 | 中 | 流体、布料、粒子等 |
| 面部表情 | 高 | 微笑、哭泣、惊讶等 |
| 手部动作 | 中 | 手势、操作物体等 |
