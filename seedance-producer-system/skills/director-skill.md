# 导演讲戏 Skill

## 技能定位

深度解析剧本，设计叙事结构，输出讲戏指导，为美术总监和分镜师提供清晰的创作方向。

## 触发条件

- Gate 0 已通过，需要进行剧本分析
- 用户请求"分析剧本"、"拆解剧情"、"讲戏"

## 输入

- 原始剧本文本
- `outputs/00-project-brief.md`（项目简报）

## 执行步骤

### Step 1: 剧本深度分析
1. **提取核心叙事**
   - 一句话故事线（Logline）
   - 核心冲突是什么
   - 主题和情感基调

2. **人物清单**
   - 主要角色（2-4 个）：姓名、身份、动机、弧线
   - 次要角色：姓名、功能、出场场景
   - 角色关系图

3. **场景清单**
   - 每个场景的时间、地点、参与角色
   - 场景的核心事件
   - 场景的情感基调

4. **情感弧线**
   - 开场情绪
   - 上升动作
   - 高潮
   - 结局
   - 每个转折点的具体时刻

### Step 2: 讲戏指导生成
1. **角色内心指导**
   - 每个主要角色在关键场景的内心独白
   - 角色的情感状态和动机
   - 表演指导（眼神、肢体、语气）

2. **镜头语言设计**
   - 关键场景的景别建议（特写/中景/全景）
   - 运镜建议（推进/拉远/跟踪/环绕）
   - 节奏控制（快切/慢推/停顿）

3. **对 L3 执行层的指导**
   - 对 Art Director 的视觉指导：风格、色调、氛围
   - 对 Storyboard Artist 的分镜指导：重点镜头、节奏、情绪节点

### Step 3: 导演讲戏本输出
1. 使用 `outputs/01-director-analysis.md` 模板
2. 填写所有分析结果
3. 确保对 L3 的指导清晰可执行

## 输出格式

产出文件：`outputs/01-director-analysis.md`

## 质量标准

- 叙事结构完整，有明确的起承转合
- 人物清单不遗漏关键角色
- 每个场景有清晰的情感基调标注
- 对 L3 的指导具体、可执行，不模糊
- 镜头语言建议使用专业术语
