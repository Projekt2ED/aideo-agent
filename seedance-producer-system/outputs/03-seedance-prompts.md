- [ ] 所有分镜均有 `[STYLE LOCK]`，且精确到胶片型号/掌镜人/LUT
- [ ] 所有分镜均声明了段落类型
- [ ] 色卡锚定存在且精确到色号
- [ ] 环境/人物/服装锚定存在且有角色说明
- [ ] 贯穿锚点声明存在，且首/中/尾都有状态描述
- [ ] 运镜使用导演风格命名或专业复合运镜描述

- [ ] 末尾有音效闭环
- [ ] 画面描述包含宏观+中观+微观三层
- [ ] 光线有演化描述
- [ ] 提示词为纯中文，无英文混杂
- [ ] 每个分镜只有一个完整提示词，不重复
- [ ] 合规审核通过（无裸露、无物理暴力、无政治敏感）
